# 🐦 Horror Flappy Bird

A 2D horror-themed arcade game developed using Unity and C#.

## 🎮 Play the Game

Play the game online on itch.io:

**[Play Horror Flappy Bird](https://charanamith.itch.io/horror-flappy-bird)**

## 📖 About the Game

Horror Flappy Bird is a horror-themed version of the classic Flappy Bird game. Control the bird, avoid obstacles, and try to achieve the highest score while experiencing a spooky atmosphere.

The project was created to explore 2D game development using Unity, including player movement, collision detection, scoring, and sound effects.

## ✨ Features

- 2D arcade gameplay
- Horror-themed visuals and atmosphere
- Bird movement and flap mechanics
- Obstacles and collision detection
- Score tracking
- Game-over system
- Sound effects

## 🎮 Controls

- **Spacebar:** Make the bird flap and move upward.
- **Avoid obstacles:** Stay in the air and navigate through the gaps.
- **Objective:** Survive as long as possible and achieve a high score.

*Controls may vary depending on the published version.*
